# E-commerce Admin Panel — Node.js + MySQL

A server-rendered admin panel for managing an e-commerce store, built with Node.js/Express and MySQL, using the AdminLTE dashboard theme.

## 🛠 Tech Stack

Node.js · Express · MySQL · AdminLTE (Bootstrap)

## 🚀 Getting Started

```bash
npm install
npm start
```

Before the first run:
1. Configure your MySQL connection in the `config/` directory.
2. Import/create the database schema for your local MySQL instance.

## 📁 Project Structure

- `server.js` — application entry point
- `routes/` — Express route definitions
- `controllers/` — request handlers
- `models/` — data models
- `views/` — server-rendered templates
- `assets/` — static assets / AdminLTE theme
- `config/` — application & database configuration
